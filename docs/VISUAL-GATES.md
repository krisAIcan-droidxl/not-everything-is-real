# Visual gate contract

The storyboard is a visual contract, not loose inspiration.

## Global rules
- No chapter is implemented cinematically before its master frame is approved.
- A locked chapter is not redesigned by work on later chapters.
- Transitions must be causal; avoid conventional section fades.
- Floor/world anchors remain spatially coherent.
- Glitches represent corrupted information, not decorative particles.
- HUD stays screen-space locked.
- Structural motion must reverse deterministically with scroll.
- Ambient dust/static/micro-glitches remain alive when scroll stops.

## Build order
01 SIGNAL → 02 FORMATION → 03 PROGRAM → 04 POLARIZATION → 05 SILENCE → 06 QUESTION → 07 REPROGRAM → 08 HUMANITY → 09 KINDNESS → 10 LABELS → 11 CREATE.

Each gate asks: Does the start match? Is the transition physically/visually causal? Does the end match?
